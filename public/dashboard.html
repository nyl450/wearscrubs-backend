🔄 Gambaran besar alur pesanan

            
Order masuk → Konfirmasi Bayar → (Bordir, jika ada) → Kemas → Kirim (+resi) → Selesai. Stok otomatis berkurang saat konfirmasi bayar.

        


        

            
1. Masuk (Login)

            
Buka dashboard → isi username & password → klik Masuk. Lupa password? Hubungi James (jangan coba berkali-kali, akun bisa terkunci sementara).

        


        

            
2. Mencatat Pesanan (Kasir)

            
Menu Kasir (walk-in toko, event/bazar, atau order via WhatsApp):

            
    
                
  1. Isi Data Pelanggan (nama, no WA, kota, alamat, berat, ekspedisi, ongkir, metode bayar). Pilih ekspedisi "Free Ongkir"/"Kirim sendiri" → ongkir otomatis 0.
    2. 
                
  2. Pilih Produk → Warna → Variant → Ukuran → Jumlah. Muncul info stok (hijau aman / kuning menipis / merah habis).
    3. 
                
  3. Bordir (Atasan, Gown & Cap): klik kotak Nama/Logo lalu isi detailnya. Posisi untuk Cap = depan/belakang, selain itu kiri/kanan dada. Celana & aksesoris tidak bisa bordir.
    4. 
                
  4. Mau tambah produk → Tambah Produk. Diskon opsional (5% / 30%).
    5. 
                
  5. Klik Simpan & Generate Invoice WA → tombol jadi abu-abu "Tersimpan".
    6. 
                
  6. Klik Kirim ke WA Customer → WhatsApp terbuka berisi pesan + instruksi bayar. Kirim.
    7. 
                
  7. Order berikutnya → Order Baru.
    8. 
            

            

                
✏️ Ukuran Custom (mis. 4XL): di pilihan Ukuran pilih "Custom Size…", isi label + harga. Barang dijahit dulu (lihat poin 4).

                
🎨 Warna Custom (di luar katalog): di pilihan Warna pilih "Custom Warna…", isi label warna + harga, lalu pilih ukuran. Stok tidak dipotong, barang dijahit dulu.

                
📦 Jumlah > stok: muncul tombol Jadikan Pre-Order (barang menyusul). Lihat poin 4.

                
🎁 Bonus: centang "Jadikan Bonus" kalau item gratis.

            

        


        

            
3. Konfirmasi Pembayaran

            
Pelanggan sudah transfer & kirim bukti → buka pesanan di menu Pesanan → Konfirmasi Pembayaran → upload foto bukti. Stok otomatis berkurang.

            
⏰ Pelanggan wajib bayar maksimal 2×24 jam; lewat itu sebaiknya dibatalkan.

        


        

            
4. Pre-Order & Custom (barang belum ada / dijahit dulu)

            
Pesanan Custom/Pre-Order tidak bisa dikemas sampai barang siap.

            
    
                
  • Custom: setelah baju jadi → buka pesanan → Tandai Siap. Kalau ada bordir, bordir baru bisa ditandai selesai setelah semua item custom ditandai siap.
    • 
                
  • Pre-Order katalog: otomatis siap begitu Anda Terima Stok ukuran itu (poin 7). Tak perlu klik.
    • 
                
  • Lihat antrian di menu Pre-Order (ada umur hari-nya).
    • 
            

        


        

            
5. Bordir → Kemas → Kirim → Selesai

            
    
                
  • Bordir (jika ada): setelah dibordir → buka pesanan → Bordir Selesai → centang konfirmasi (foto opsional) → siap dikemas.
    • 
                
  • Kemas: buka pesanan → Kemas → centang konfirmasi "sudah dikemas rapi + isi sesuai pesanan" → Konfirmasi Dikemas (foto opsional).
    • 
                
  • Kirim: Kirim → isi Nomor Resi (& kurir) → Kirim Resi ke Customer (WA ke pelanggan). Kalau antar sendiri, kurir "Kirim sendiri", resi boleh kosong.
    • 
                
  • Selesai: setelah barang sampai, ubah status pesanan jadi Selesai.
    • 
            

        


        

            
6. Membatalkan Pesanan

            
Hanya sebelum dikirim. Buka pesanan → Batalkan → isi alasan. Kalau sudah dibayar, stok otomatis dikembalikan. Pesanan yang sudah dikirim tidak bisa dibatalkan.

        


        

            
7. Menerima Stok dari Penjahit

            
    
                
  1. Menu Inventori → cari produk + ukuran/warna.
    2. 
                
  2. Klik tombol ➕ (Terima Stok) → isi jumlah masuk → simpan.
    3. 
                
  3. Kalau ada Pre-Order menunggu ukuran itu → otomatis terpenuhi (muncul pesan) & pesanan jadi siap dikemas.
    4. 
            

            
Varian yang ada antrian PO diberi tanda oranye "N PO" di Inventori.

        


        

            
8. Tukar Size & Refund

            
    
                
  • Tukar Size: dalam 3 hari setelah pesanan Selesai. Menu Tukar Size → pilih item → ukuran baru. Stok otomatis disesuaikan. Bukan refund uang.
    • 
                
  • Refund uang HANYA untuk bordir yang ditolak. Menu Refund → proses → upload bukti transfer. Produk tidak pernah dikembalikan uangnya — hanya tukar ukuran.
    • 
            

        


        

            
⭐ Aturan Penting

            
    
                
  1. Produk tidak pernah refund uang — hanya tukar size.
    2. 
                
  2. Refund uang hanya untuk bordir yang ditolak.
    3. 
                
  3. Bordir untuk Atasan, Gown & Cap (bukan celana/aksesoris).
    4. 
                
  4. Pelanggan wajib bayar maksimal 2×24 jam.
    5. 
                
  5. Custom & Pre-Order harus siap dulu sebelum dikemas.
    6. 
                
  6. Selalu kirim WA konfirmasi setelah catat order, dan kirim resi setelah dikirim.
    7.
